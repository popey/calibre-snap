# Store assets

- `calibre.svg`: original upstream vector artwork, sized to **512×512**;
  original `viewBox="0 0 1024 1024"` preserves the full vector artwork.
- `screenshots/01-library.png`: browse seven classics by cover.
- `screenshots/02-reader.png`: Pride and Prejudice, chapter I, with navigation.
- `screenshots/03-metadata.png`: edit book details and cover artwork.

All screenshots are **1600×900 PNGs**, captured directly from the installed
Calibre snap. They exclude desktop chrome and personal-library data. No UI
content was composited or fabricated.

Icon source:
https://github.com/kovidgoyal/calibre/blob/43919601f2736524fb2ba05f6f875b6819391df0/resources/images/calibre.svg
Retain upstream artwork attribution and licensing. This package is not endorsed
by the Calibre project.

The isolated demo library is in `artifacts/store-demo/Classics/` (ignored by git).
